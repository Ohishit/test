# 校园活动与机会聚合平台

## 产品名称
校园活动与机会聚合平台

## 解决的问题
针对校园内信息来源繁杂、质量参差不齐的痛点，帮助新生和在校学生快速浏览、筛选和理解讲座、竞赛、项目招募、学生自主发布等各类校园信息。

## 核心功能
1. **活动列表展示**：清晰呈现题目提供的模拟校园信息，区分学校/学院发布与学生个人发布。
2. **分类筛选**：支持按“讲座课程”、“学生发布”等类型快速过滤信息。
3. **自主发布**：学生可以主动发布自己的活动或招募信息，并实时进入列表。
4. **本地存储（创新点）**：用户发布的内容通过 localStorage 自动保存在浏览器中，刷新或重新打开页面后数据依然保留，无需后端数据库即可实现持久化。

## 运行方式
直接访问在线链接即可使用：[在线作品链接](https://ohishit.github.io/test/)
或者下载 `index.html` 在浏览器中打开。

## 主动发现并处理的关键问题
在信息处理中，发现了学生自主发布信息可能存在“内容缺失”（如地点未确定、需加私人微信）的问题。我在设计时保留了这些信息的不确定性描述，没有擅自编造，并通过标签将其与官方信息区分开，以提醒用户注意辨别。

## 下一步希望完善的内容
如果继续开发，希望增加“信息发布时间线”和“真实性举报/标记”功能，进一步解决多来源信息的质量控制问题。
